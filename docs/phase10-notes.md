# Phase 10 - System Monitoring & Resource Analysis

## Objective

Monitor Linux system resources and identify potential performance issues.

## Commands Used

- free -h
- vmstat
- uptime
- lscpu
- lsblk
- df -h
- du
- top

## Skills Demonstrated

- Analyze memory usage
- Monitor CPU information
- Inspect disks
- Verify system uptime
- Monitor running processes
- Create a health report
